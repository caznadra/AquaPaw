# AquaPaw
## Det bästa för din bästavän

### Syfte och målgrupp


Syftet med gruppens projekt är att med hjälp av en sensor och PHmätare avläsa vattenmängd och vattnetsPHvärden i djurs vattenskål. Målgruppen vi vill nå ut till är djurägare. Med hjälp av en lysdiod ska ägaren signaleras ifall vattnert behöver bytas eller fyllas på.
