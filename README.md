# AquaPaw
---

## Inledning

Att se till att husdjur får i sig tillräckligt med vatten är viktigt för djurets hälsa och välmående. Det kan dock vara svårt för djurägare att hålla koll på hur mycket vatten deras husdjur dricker och när vattenskålen behöver fyllas på.

Därför har vi valt att utveckla AquaPaw, ett smart system som med hjälp av sensorer mäter vattennivån i djurets vattenskål och registrerar hur mycket vatten djuret dricker. Genom en tillhörande applikation ska djurägaren kunna följa husdjurets dagliga vattenintag och få notiser när det är dags att fylla på skålen.

AquaPaw ska göra det enklare för djurägare att hålla koll på sina husdjurs vattenvanor och upptäcka eventuella avvikelser.

## Eventuella hinder och lösningar

- ### 1) Flera husdjur: 

Vi fokuserar först på ett husdjur. Att ha flera husdjur som dricker ur samma skål kan vara ett problem, eftersom man inte vet vilket djur som har druckit vatten och hur mycket.

- ### Lösning: 

RFID-teknik (Radio Frequency Identification) kan användas för att identifiera olika husdjur och registtrera deras individuella vattenförbrukning.

---
- ### 2) Mätning: 

Vissa husdjur kan leka med vattnet, vilket kan orsaka spill och påverka mätningen. Det kan leda till felaktiga värden.
 
 - ### Lösning:

 Filtrering av mätdata kan minska påverkan från spill och felaktiga mätvärden.

---
## Avslutning

AquaPaw. Påminner dig om när vattent minskar och ger dig insikter i husdjurets vattenvanor, nu- och framtid.

- Vattennivåsensor för noggranna mätningar av vattenskålen.
- Notera förändringar innan det gått för långt!
- Gör vardagen tryggare och smidigare, för både dig och ditt husdjur.
